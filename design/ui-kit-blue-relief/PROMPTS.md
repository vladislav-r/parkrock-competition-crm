## Уточняющий проход для каждого изображения

Edit this UI-kit board. Preserve composition, variant title, all card geometry, colors, typography, navigation and component specimens. Correct data consistently everywhere: total participants 320, arrived 240/320 = 75%. Set 1 80/100 = 80%; set 2 72/80 = 90%; set 3 88/100 = 88%; set 4 80/100 = 80%. Every set-2 percentage must say 90%, including bottom set card and top mini chart, and its bar should be 90% filled. Every set-3 bar says 88/100,88%. Do not introduce other metrics. Neutral gray badges for Ожидает (not amber). Do not name the festival Голубой рельеф (that is the design system name): use Скалолазный фестиваль. Date only 14 сентября 2026; no invented city or venue. If a navy festival detail card exists, remove invented disciplines Скорость and Трудность and all discipline list, replace with «Этап: Квалификация», «Сеты: 4», «Участники: 320». Remove any invented slogan. Keep all text legible Russian. This is a targeted cleanup of text/data; do not redesign.
