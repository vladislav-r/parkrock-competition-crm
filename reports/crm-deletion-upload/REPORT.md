# Удаление участников и клубов, загрузка файлов заявок из CRM

Локально, 14.09.2026. На VPS не опубликовано. Миграции не требуются.

## Поведение

- Меню участника: удаление с подтверждением ФИО и номера, только на подготовке текущего соревнования.
- Меню клуба: существующая форма редактирования и удаление самого клуба со всеми участниками, включая индивидуальные заявки и невыбранные строки.
- Удаление проверяет версии, состав клуба, этап и отсутствие результатов. Повтор с тем же `X-Operation-Id` возвращает исходный ответ. Операция записывается в журнал.
- Права удаления участника: `participants.manage`. Для клуба требуются `clubs.manage` и `participants.manage` одновременно.
- В «Заявках» кнопка «Импорт» открывает окно выбора/перетаскивания одного XLSX/XLSM до 10 МБ. Используется общий с лендингом серверный валидатор с показом ошибок строк. Файл сохраняется для скачивания и последующего импорта; участники автоматически не создаются.
- Повторная загрузка одинакового файла возвращает существующую заявку. Загрузка из CRM разрешена с `participants.import`, в том числе для непубличного текущего соревнования; действие записывается в журнал. Из CRM уведомления в Telegram не отправляются.
- Сохранены локальные изменения оформления раздела заявок, существовавшие до этой задачи.
