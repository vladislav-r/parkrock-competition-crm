# Раздел «Заявки»: оформление и загрузка файлов

- Обновлено оформление списка, пустого состояния, статусов и действий заявок; сохранена адаптация для телефонов.
- Кнопка «Импорт» открывает выбор файла и drag-and-drop для XLSX/XLSM до 10 МБ.
- POST /api/v1/admin/applications использует общий с лендингом валидатор и требует participants.import. Ошибки строк показываются в окне загрузки.
- Сохраняется только файл заявки, доступный для скачивания и дальнейшего импорта участников. Повторная загрузка идентичного файла не создаёт дубликат.
- Загрузка работает для текущего непубличного соревнования, записывается в журнал и не отправляет уведомление в Telegram.
- Изменений схемы базы нет. На VPS не опубликовано.

Проверки: backend/tests/test_crm_applications.py, существующие test_applications.py и test_application_acceptance.py; scripts/test-crm-applications.cjs, TypeScript и production-сборка. Backend-тесты используют только climbhub_test, браузерный сценарий перехватывает все изменения CRM тестовыми ответами.
