# Командный зачёт · 14.09.2026

Реализовано локально. На VPS не выложено; пользовательская приёмка отдельно.

## Результат

- Единая квота на все возрастные группы и оба этапа, по умолчанию 2; изменяется в CRM с подтверждением пересчёта, проверкой прав `publication.manage`, версии записи и безопасным повтором операции. Изменение отражается в журнале.
- В каждой группе личные места переводятся в баллы ФСР. Лучшие участники каждого клуба в пределах квоты дают вклад группы; сумма всех групп определяет результат клуба. Клуб определяется по устойчивому идентификатору, название берётся из справочника. Одинаковые названия разных записей справочника автоматически не объединяются.
- Квалификация и финал считаются независимо, после подтверждения всех категорий соответствующего этапа. Квалификация после запуска финала берётся из снимка. Финал использует уже рассчитанные личные места, включая действующие критерии равенства, и только участвующие группы. Участники без личного места/результата не начисляют баллы; отсутствие клуба не исключает участника из расчёта равных личных мест.
- Точные рациональные суммы без промежуточного округления; квота не расширяется, командные места 1, 1, 3. На сайте и ТВ показ до трёх знаков; точные дроби доступны в подсказках и расшифровке XLSX.
- CRM разбита на карточки квоты, готовности итогов, таблицы баллов и официальных документов ФСР. Публичная заглушка `/teams` заменена вкладками «Квалификация / Финал» и раскрываемым положительным вкладом участников по группам.
- «Выгрузки → Результаты → Командный зачёт»: четыре XLSX — итог и вклад участников для каждого этапа. Общая шапка, реквизиты, права, фильтры и журнал сохранены. Незавершённый/неоднозначный зачёт нельзя выгрузить подтверждением неполных данных.
- ТВ: отдельная галочка командного зачёта, сохранение в ссылке `teams=1`, показ по выбранному этапу, возможность показа только команд. В цикле используется общий механизм смены страниц, снимка и восстановления связи.

## Оставшееся ограничение

Официальное разъяснение противоречащих условий приложения 2 для случая, когда ровно половина разделённых позиций находится ниже 30-й, не найдено. Произвольное правило не добавлено: при таком случае соответствующий командный зачёт и его XLSX недоступны, CRM и сайт объясняют причину. Остальные случаи рассчитываются по изученной модели. Длительная проверка ТВ на HDMI и выкатка на VPS не проводились.

В CRM добавлены официальные [правила ФСР](https://rusclimbing.ru/docs/pravila-sorevnovaniy/), [положение 2026, приложение 2](https://rusclimbing.ru/upload/iblock/b08/32xj3kh3cb9g4ijdjgsj1s27sx0slgq2/2026_pol.pdf#page=48) и [нормативные документы](https://rusclimbing.ru/docs/normativnye-dokumenty/). Повторно проверена доступность страниц ФСР; повторное чтение большого PDF через web-инструмент ограничено размером, таблица и неоднозначность взяты из ранее визуально проверенного исследования №11.
