# Логотип CRM ПаркРок

Основной источник — папка «ЛОГО-Управление соревнованиями/SVG-вектор».
SVG перенесены без изменений. Фон прозрачный, текст в контурах, внешние шрифты и растровые вставки отсутствуют.

- `full-light.svg`: «Полный-светлая-тема.svg», страница входа.
- `full-dark.svg`: «Полный-тёмная-тема.svg», шапка.
- `compact-light.svg`: «Компактный-светлая-тема.svg», состояние загрузки.
- `compact-dark.svg`: «Компактный-тёмная-тема.svg», мобильная шапка.
- `mobile-blue.svg`: «Мобильный-знак-синий.svg».
- В `src/app/admin` и `src/app/judge` файл `icon.svg` — копия мобильного знака. `apple-icon.png` — экспорт этого же SVG в 180×180 на белом фоне, для совместимости с ярлыками iOS.

Макеты интерфейсов и палитра из исходного набора служат референсами, а не изображениями для вставки в рабочие экраны. Логотип публичного фестиваля хранится отдельно и не заменяется логотипом CRM.
